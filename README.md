# 🧠 Lógica de Programação & Algoritmos (Python & JavaScript)

[![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/)

Este repositório reúne os exercícios, algoritmos e atividades desenvolvidos durante o módulo de **Lógica de Programação** do curso de Desenvolvimento de Sistemas. O projeto abrange fundamentos do pensamento computacional aplicados em **Python** e **JavaScript**, com organização dividida em *branches* temáticas.

---

## 🌿 Organização das Branches

| Branch | Linguagem / Foco | Descrição do Conteúdo |
| :--- | :--- | :--- |
| 📌 `main` | **Python** | Base principal contendo a introdução à lógica, condicionais, loops e funções. |
| 🔀 `Logica_JavaScript` | **JavaScript** | Resolução de exercícios de lógica utilizando a sintaxe e métodos do JavaScript. |
| 📑 `Atividades_Pontuadas` | **Python / JS** | Exercícios avaliativos, trabalhos práticos e desafios pontuados das disciplinas. |

---

## 📚 Conteúdos & Conceitos Abordados

* **Fundamentos:** Algoritmos, variáveis, tipos de dados (`string`, `int`, `float`, `boolean`).
* **Estruturas de Decisão:** Tomada de decisão em código (`if`, `else`, `switch` / `elif`).
* **Laços de Repetição:** Iterações e automação de tarefas com `for`, `while` e `do-while`.
* **Coleções de Dados:** Manipulação de vetores, matrizes, listas e arrays.
* **Modularização:** Criação e reuso de funções com parâmetros e retornos.
